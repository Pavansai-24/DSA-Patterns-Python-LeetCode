# Binary Tree Pattern

This folder contains Binary Tree problems solved from LeetCode.

## Key Concepts
- Depth First Search (DFS)
- Breadth First Search (BFS)
- Recursion
- Tree Traversals (Preorder, Inorder, Postorder)
- Level Order Traversal
- Height / Depth Calculation

## Goal
Build strong recursion and tree traversal fundamentals for interviews.
